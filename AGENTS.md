# Repository guidance

## Product documentation and marketing

Keep `README.md` and the companion pbcms page at `../pbcms/src/content/projects/astro-wysiwyg/index.md` accurate when a change affects public behavior, setup, configuration, compatibility, safety guidance, or project status.

Keep the facts aligned, not the copy. `README.md` owns installation, configuration, development, and contributor instructions. The pbcms page presents the problem, value, key strengths, visuals, and destination links. Do not copy command sequences or development procedures into the pbcms page.

When you create or replace a marketing artifact such as a screenshot, GIF, video, poster, badge, or release description, update the relevant `README.md` reference and the pbcms page or its assets in the same work. The published page is `/projects/astro-wysiwyg`.

Verify public claims against the current package and tests. If the sibling pbcms checkout is unavailable, name the required page update in the completion report instead of claiming the documentation is complete.
